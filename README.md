The python code for kernel embedded doubly robust estimator.

"ASCVD.cvs" records the data for estimating the average treatment effect of hypotensive drug on Atherosclerotic Cardiovascular Disease,
which is collected from UK-biobank.

To check the mathematical derivation of the kernel embedded doubly robust estimator and the analysis on the convergence and asymptotic normality,
please see Supplementary/Main.pdf.
